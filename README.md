# KOKORO MEMO

感情付きで日記を記録できるメンタルログアプリです。

## Features

- 感情アイコン選択
- 日記の作成 / 編集 / 削除
- 一覧表示
- Firebase Authentication ログイン
- Firestore 永続化
- Expo Router (Tabs + Stack)

## Tech Stack

- React Native (Expo)
- TypeScript
- Firebase
- Expo Router
